## מערכת ניהול הודעות

## להוספת הודעה אפשר לשלוח בקשת get לכתובת ``http://localhost:3000``

שם מחכה דף html למילוי הפרטים, שים לב! יש למלא את כל הפרטים 


לאחר לחיצה על 'שלח' הטופס ישלח דרך הapi לאנדפוינט post/contact וישמר בדאטהבייס המקומי

## לצפיה בפניות הקיימות במערכת יש להיכנס לכתובת ``http://localhost:3000/admin``
שם יש גם אופציה למחוק פניות באמצעות כפתור שנמצא על כל אחד מהם

ואז מאחורי הקלעים יש פונקציה שקוראת לאנדפוינט delete/contact

#
 כל האנדפוינטים נשלחים באמצעות ה server ל controller ושם מטופלים 

 הקריאה והכתיבה לדאטהבייס היא מהקובץ storage.js

 הדף index.html הוא הדף שבו מוסיפים את הפניות החדשות 

 והדף admin.html הוא דף התגובה עם הרשומות ששמורות במערכת


 ## כמובן שלפני הקריאה לאנדפוינטים יש להפעיל את השרת. עם הפקודה ``npm start``
